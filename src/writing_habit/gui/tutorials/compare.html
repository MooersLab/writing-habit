Compare plan and effort

The compare report sets the planned minutes of a week beside the minutes you worked. Run it any day of the week to see where you stand.

The Compare tab with the report for the practice week.

In the window

  1. Sync first, so the report includes today, as in Import writing effort.
  2. Open the Compare tab and choose compare.
  3. Set week to any date in the week and press Run.
  4. To also get a bar chart, send plot with a file name such as week.png. The chart opens in the Preview pane. The chart needs matplotlib, which pip install "writing-habit[plot]" adds.

At the command line

writing-habit compare --week 2026-10-05 --db ~/org/writing-habit.db
writing-habit compare --week 2026-10-05 --db ~/org/writing-habit.db --plot week.png

Reading the report

SectionQuestion it answers
Overall adherenceWhat share of the planned minutes did I work?
By projectWhich projects got their time and which were starved? A value above 1.00 means more time than planned.
By activityDid generative writing give way to easier editing or support?
By barbell classDid the risky projects keep their share, or were they the first to go?
StreakHow many days in a row have I written?

A project that shows planned minutes and an actual of zero was either not worked or not matched by the sync. The sync report says which.
