Dashboard

The dashboard is a single HTML page for one week. It holds the same numbers as the compare report, drawn as charts, and it needs no server or network to open.

The dashboard of the practice week, light theme.

In the window

  1. Import the plan and sync the effort, as in the earlier tutorials.
  2. Open the Compare tab and choose dashboard.
  3. Set week to any date in the week.
  4. Set out to the page to write, for example ~/org/dashboards/2026-10-05.html.
  5. Press Run. The page appears in the Preview pane on the right. Open outside opens it in your web browser.

The Preview pane draws the page roughly unless the optional web engine is installed. Install it with pip install "writing-habit[preview]", or open the page in your browser.

At the command line

writing-habit dashboard --week 2026-10-05 \
    --out ~/org/dashboards/2026-10-05.html --db ~/org/writing-habit.db
open ~/org/dashboards/2026-10-05.html

The whole end-of-week routine is three commands.

whsync
writing-habit compare --week 2026-10-05 --db ~/org/writing-habit.db
writing-habit dashboard --week 2026-10-05 --out ~/org/dashboards/2026-10-05.html \
    --db ~/org/writing-habit.db

What the page shows

  • Summary tiles with the planned minutes, the actual minutes, adherence, and the streak.
  • A trend of overall adherence over recent weeks.
  • The week's schedule redrawn as a grid, colored by activity.
  • Planned against actual for each project, with an adherence column.
  • The balance of generative, editing, and support work.
  • The barbell split between safe and risky projects.
  • When the week has any, the risky prospecting, which is work on writing projects that are on no list, with the weeks each has gone unplanned. A row in orange has gone unplanned for three weeks or more. Put that project on a semester list and give it a block, or let it go.

A button in the corner switches between the light and the dark theme. The dashboard and the text report round percentages differently, so a share may differ by one point between them.
