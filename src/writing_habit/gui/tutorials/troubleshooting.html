Troubleshooting

The sync leaves out nearly every row

Read the report. If it says in weeks with no legend to read, the plan of that week was never imported. Import it as in Import the plan, then sync again. On the Track tab the table field also lends the open table's legend to any week without a plan.

If it says not in the week's legend, the project numbers of those rows appear in neither the legend nor the current semester list. Make sure each Project entry begins with the four-digit project number, such as 0374qflip, and that the project is on the current semester list.

Adherence is empty or zero

Adherence divides actual minutes by planned minutes. With no plan imported for the week there is nothing to divide by. Import the plan.

A project shows the wrong name in a report

A code such as Z keeps the name it had the first time a plan named it, because codes are reused from week to week. The minutes are still counted under the right code for each week.

A deleted block still counts as planned

Plan import adds blocks and never removes them. To load a changed week from scratch, clear that week's plan and import it again.

sqlite3 ~/org/writing-habit.db "DELETE FROM plan_block WHERE week_start = '2026-10-05';"
writing-habit plan import ~/org/writing-schedule/tables/Oct5.org --week 2026-10-05 \
    --db ~/org/writing-habit.db

A command ran against the wrong database

The status bar names the database the last command used. Every form has its own db field, seeded from the last one you used, so check it before pressing Run.

The deadline will not save

A deadline must be a real date written YYYY-MM-DD, such as 2026-11-15. Leave the cell empty for no deadline.
